# 家庭餐桌 · 双视图版

> **在线预览**：<https://pumpkinlao-coder.github.io/family-meal-planner/>  
> **验收包下载**：[家庭餐桌-DeepSeek验收包-修复版.zip](https://pumpkinlao-coder.github.io/family-meal-planner/dist/家庭餐桌-DeepSeek验收包-修复版.zip)

本项目给同一户家庭提供简选和完整两个入口。日常从简选视图查看菜单、换一餐和买菜。想调整食材克数、米饭方案或查看分装依据时切到完整视图。

## 给 DeepSeek 的运行与验收说明

请解压完整项目，在含有本 README 和 index.html 的目录运行下列命令。使用 Python 3 即可，无需安装前端依赖。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

用浏览器访问 [简选版](http://127.0.0.1:8000/index.html#simple) 或 [完整版](http://127.0.0.1:8000/index.html#full)。测试结束按 Ctrl+C 停止。做 iPhone 实机检查时，将绑定地址换成本机 Wi-Fi 地址，手机连同一 Wi-Fi，用该地址替代链接中的 127.0.0.1。保持同一主机和端口，以便比较刷新前后的计划。

## 用超市冷冻品安排早餐

在早餐换餐处选择小米糕、小笼包或饺子的组合。三种主食均指从盒马或其他超市买到的预包装冷冻品。购买时按页面的家庭需要量与包装净含量选袋数。购物清单中的配餐也要一起核对。

使用前看清手上这袋的四项信息：

- **加热方法**。选购包装明确支持蒸制的产品。按标签决定是否解冻、何时开始计时、一次蒸多少。生制肉馅需要按生制食品要求彻底蒸熟。小笼包出锅后注意汤汁温度。
- **成分与过敏原**。同品类的配料、调味和“可能含有”声明随产品变化。尤其核对饺子馅、小笼包皮馅和小米糕中的蛋奶或小麦。家庭有过敏排除项时，以这袋产品的标签核实。
- **每份重量与营养**。同名商品可能有不同克重。营养标签如果按每 100 克列值，实际摄入估算为“标签值 × 食用克数 ÷ 100”。成品的页面参考量不代表某个盒马商品的实测数据。
- **冷冻保存**。遵循标签标示的保存温度、保质期和开袋说明。按当次早餐用量取出，其余及时放回冷冻室。

## 设计参考

[Tandoor Recipes](https://github.com/TandoorRecipes/recipes) 将食谱、餐单与采购组织在一个应用里。本项目沿用同一份菜单推导采购、营养和备餐任务的思路，通过两个视图满足不同操作习惯。[FoodSafety.gov 的食品安全指引](https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety)强调商业冷冻食品遵循具体产品的包装说明，因此不为不同品牌统一指定蒸制时间。

## 回退

本版部署在外置硬盘项目的独立子目录。需要回到上一版时，打开上一级的 index.html，或上一级“简选版”文件夹的 index.html。原文件和旧版浏览器记录保留。整套文件一起复制时请保留 assets 目录。

## 打开、切换与备份

打开本目录 index.html 进入完整版，打开“简选版/index.html”进入简选版。两者最终打开同一份页面，用页首按钮切换。请在同一个浏览器、同一份文件位置使用；复制到另一设备或另一目录时，可用“计划备份与导入”转移计划。

新版单独保存计划。若浏览器允许读取旧记录，可在备份入口选择要采用的计划；浏览器对本地文件的隔离可能导致旧记录不可见。遇到这种情况，旧计划仍能从原来的网页打开。导入新版计划前也可先导出一份 JSON 备份。

没有具体商品标签时，这三种冷冻品本身的营养数据暂缺，页面小计仅含已知食材。开启过敏原排除后，未核实配料的冷冻品不进入推荐。

## 本轮修复（DeepSeek 验收反馈）

- **冷冻成品详情**：没有可信营养标签时，弹窗里的营养卡片显示“待核”，不显示 0 kcal/0 g；过敏原显示“含：未知（成品包装未核对）”，不再显示“含：无”。
- **缺少工具**：菜单顶部直接提示缺少的工具和受影响菜品（例如关闭蒸锅后提示“缺少蒸锅：会影响冷冻小米糕、冷冻小笼包、冷冻饺子”），不用再点进备餐模块才发现。
- **营养完整性**：冷冻成品营养未知时，营养页增加“有 N 餐含超市成品，成品营养未知”的提示，并在当天标“营养待核”；“已计 10/10 餐”只表示餐次确定，不再暗示营养完整。

## 历史验证记录（早于本轮最终改动）

已用 Chrome 在 390 × 844 视口检查两个入口、跨视图切换及五日菜单。三种冷冻早餐均通过换餐选中并进入采购；选饺子后切到简选版并刷新仍保留，打开小麦排除后对应早餐进入待选。测试视口未见页面横向溢出。

## 手机与桌面菜单

默认按天列出各餐菜名，点「详情 / 换餐」展开当天食材、热量、保存方式及换餐控件。家庭摘要仅显示计划天数、成员、餐次及已排除项。手机将八个分区排成两行，桌面导航空间不足时自动换行。

在「家庭设置与饮食偏好」（完整版为「调整细节」）的「早餐风格」选择「超市冷冻早餐（蒸锅）」，即可按小米糕、小笼包、可蒸饺子轮换。五日计划后两天重复小米糕和小笼包。
